# LMS & CBT Jurusan Animasi - SMK Islam 1 Durenan

Sistem Learning Management System (LMS) dan Computer-Based Test (CBT) berbasis web untuk Kompetensi Keahlian Animasi, SMK Islam 1 Durenan.

## Fitur Utama
- **Multi-Role Login**: Admin, Guru, dan Siswa.
- **Database Otomatis**: Menggunakan Google Sheets & Google Apps Script API.
- **Manajemen Data & Soal**: Import dan Export data siswa, guru, jadwal, dan bank soal (PG & Uraian) via file Excel (`.xlsx`).
- **CBT Anti-Curang**: Lockdown Mode (Fullscreen), deteksi perpindahan tab/aplikasi, batas maksimal 3x pelanggaran (auto-submit), dan autosave jawaban.
- **Live Monitoring & Penilaian**: Pantau progres ujian real-time, penilaian PG otomatis, dan koreksi manual soal uraian.
- **Administrasi Cetak**: Cetak Kartu Peserta, Daftar Hadir, dan Berita Acara lengkap dengan Kop Sekolah.
